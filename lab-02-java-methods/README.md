# Lab 2 – Java Methods & Calculations

Four applications focused on reusable Java methods.

## Programs

- `FahrenheitCelsiusTable` – converts Fahrenheit values from 0–20 to Celsius
- `GradeCalculator` – calculates five letter grades and a test-score average
- `DistanceConverter` – menu-driven meter conversion to kilometers, inches, and feet
- `PresentValueCalculator` – calculates present value using `Math.pow()`

## Run

```bash
javac -d out src/*.java
java -cp out GradeCalculator
```
