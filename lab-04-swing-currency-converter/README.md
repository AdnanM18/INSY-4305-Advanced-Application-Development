# Lab 4 – Swing Currency Converter

A Java Swing desktop application for conversion among the US Dollar, Mexican Peso, and Euro.

## Features

- radio-button currency selection
- currency image assets
- formatted output
- result popup dialogs
- invalid-number handling
- Clear and Exit controls
- exit confirmation
- menu bar with About and Exit

## Portfolio Cleanup

An unrelated template-author name was removed from the About dialog, and IDE-specific image loading was changed to repository-relative asset paths. The submitted conversion logic is otherwise preserved.

## Run

```bash
javac -d out src/*.java
java -cp out ConvertApp
```
