# Lab 3 – Inheritance, Interfaces & Polymorphism

A ship hierarchy demonstrating advanced object-oriented Java concepts.

## Design

- `Displayable` interface
- abstract `Ship` base class
- `CruiseShip` subclass
- `CargoShip` subclass
- `ShipDemo` driver

## Concepts

- abstract classes
- interfaces
- inheritance
- method overriding
- polymorphism
- base-class arrays
- `ArrayList<Ship>`
- copy constructors

## Run

```bash
javac -d out src/*.java
java -cp out ShipDemo
```
